## 3. 验收标准

### 3.1 功能验收

| 编号 | 验收项 | 通过标准 |
|---|---|---|
| F1 | 手动收笺 | 输入 URL 后 ≤ 100ms 本地可见；标题/摘要异步补全 |
| F2 | 分享收笺 | 浏览器分享面板出现「流笺」；3 步内保存成功 |
| F3 | 粘贴收笺 | 点击粘贴控件无权限弹窗；识别纯链接与带文案链接 |
| F4 | HTML 导入 | 5000 条 ≤ 8s；文件夹转标签；重复跳过；失败可导出 |
| F5 | 去重 | 同 URL（含 utm 参数差异）不重复新增 |
| F6 | 搜索 | 标题/域名/摘要/摘录/标签均可命中；高亮正确 |
| F7 | 详情 | 原文、快照、摘录三态切换；编辑即时保存 |
| F8 | 标签 | 新增/重命名/合并/删除；删除不删书签 |
| F9 | 回收站 | 删除后 30 天内可恢复；到期清理 |
| F10 | 服务卡片 | 添加、刷新、点击直达、空状态均正常 |
| F11 | 深色模式 | 跟随系统切换，无闪白、无不可读文字 |
| F12 | 一多 | 手机/平板/2in1 三断点无横向滚动、无遮挡 |
| F13 | 导出 | JSON 与 HTML 均可被第三方工具读取 |
| F14 | WebDAV | 连接测试、首次全量、增量、删除同步正确 |
| F15 | 冲突 | 双端修改后较新者胜，败方可在冲突记录恢复 |
| F16 | 分布式 | 同账号可信设备可同步元数据与标签（视设备） |
| F17 | 阅读模式 | 正文可读、字号可调、无脚本执行 |
| F18 | 接续 | 手机→PC 恢复同一书签与滚动位置（视设备） |

### 3.2 数据与同步验收

- 任意同步失败不得造成本地数据丢失。
- 同步中断后再次同步可继续，不产生重复记录。
- 同一 URL 在多端只保留一条有效记录。
- 删除在双端一致；墓碑 30 天后清理。
- 凭据不以明文出现在 `preferences`、日志或导出文件中。
- 导出 → 清空 → 导入，数据条数与关键字段一致。

### 3.3 UI 验收

- 严格遵循 `03-UI设计规范.md` 的 token；无未经批准的彩色、渐变、投影。
- 三断点均通过视觉走查清单。
- 所有空状态、加载、错误均有文案。
- 触控目标 ≥ 44vp；对比度 ≥ 4.5:1。
- 键盘可完成：搜索、上下选择、打开、返回、收笺。

### 3.4 性能验收

| 指标 | 阈值 | 测量方式 |
|---|---|---|
| 冷启动 | ≤ 800ms | 2in1 真机，连续 3 次取中位 |
| 首页滚动 | 60fps | 1000 条数据，开发者工具帧率 |
| 搜索 | ≤ 100ms | 10,000 条，5 个关键词 |
| 导入 | ≤ 8s / 5000 条 | 标准 Chrome 导出文件 |
| 同步 | ≤ 30s / 1000 条增量 | 局域网 WebDAV |
| 包体 | ≤ 20MB | Release HAP |

### 3.5 质量门禁

- `check_ets_files` 对所有新增/修改 `.ets` 通过。
- `devecocli build` 成功，无 ERROR。
- Hypium 单元测试全部通过。
- 无 `any` / `unknown` / `as` 断言 / 动态属性访问（ArkTS 规范）。
- 无硬编码密钥、账号、测试 URL。
- 不申请与功能无关的权限。

## 6. 风险与应对（实施视角）

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 分享扩展在真机不显示 | 分享面板无「流笺」 | 检查 `skills`/`uris` 配置；先用官方最小样例验证 |
| 2in1 无手机形态 | 断点无法完整验收 | 用 DevEco 预览器补手机/平板走查；请用户提供第二设备 |
| WebDAV 服务商不兼容 | PROPFIND 405/501 | 切换兼容模式（Depth、Content-Type）；记录请求日志 |
| GBK 解码失败 | 中文站点摘要乱码 | 检测 charset；降级 UTF-8；提示手动编辑 |
| 同步规模膨胀 | PROPFIND 变慢 | 5000 条后切换分片清单；增加本地缓存 |
| 碰一碰/App Linking 无域名 | 无法校验 | 自定义 scheme 兜底；域名作为发布配置 |
| 全设备一多耗时 | 2in1 挤压手机布局 | 组件级断点复用，禁止两套 UI |
