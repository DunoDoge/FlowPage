### 1.4 WebDAV 同步（真机双端验证）

使用本地 WebDAV 测试服务（Basic Auth）完成闭环：

1. 手机首次同步：上传 6 条。
2. 远端修改标题并把 `updatedAt` 提前：手机同步「下载 1」，详情与列表显示新标题。
3. 手机加星标：同步「上传 1、跳过 5」，远端 JSON `starred: true`。
4. PC 配置同一 WebDAV：同步「下载 6」，三栏列表出现全部 6 条，含 1 条星标。
5. 增量同步：无变化时上传 0、下载 0。

同步特性：

- 本地 RDB 为唯一事实源；上传/下载失败不影响本地使用。
- 单条 JSON 文件，ETag 增量；LWW（`updatedAt` + `rev`）合并。
- `dirty` 标记保证本地修改在下一次同步必被上传，不依赖时间窗口。
- 凭据使用 HUKS AES-256-GCM 加密后写入 preferences；同步前在内存中解密，不落明文。
- HTTPS 建议写入 UI 提示。
- 正文快照不上传，避免体积膨胀；目标端按需重新抓取。
- 已用 HUKS 加密凭据；单一 `webdav_config` JSON 避免多键写入不一致。

### 1.5 隐私与阅读增强（批次 C）

- **HUKS 凭据加密**：AES-256-GCM，密钥别名 `flowpage_sync_credential_key`；加密结果与非对称 nonce 一起存入单一 JSON 配置，已验证保存、重启、同步。
- **失效链接检测**：详情页「查链接」执行 HEAD（必要时 GET 兜底），标记「链接可用 / 可能失效 / 未检查」并持久化。
- **阅读字号**：正文支持 A− / A+ 调节（15–21fp），偏好持久化；正文行高随字号联动。
- **脏标记同步**：`dirty` 列保证本地修改必被上传，不依赖时间窗口。
