## 方案速览

- **一句话**：把散落在浏览器、微信和各设备里的链接，三秒收进一册可离线、可搜索、可同步的「笺」。
- **核心闭环**：收 → 理 → 找 → 用。
- **差异化**：
  1. 一笺三态（链接 + 离线快照 + 摘录），对抗「收藏即吃灰」；
  2. 鸿蒙原生收笺（分享扩展 / 粘贴控件 / 碰一碰）；
  3. 时光轴 + 每日笺，让旧收藏重新流动；
  4. 本地优先 + 自己的云（WebDAV + 分布式数据）。
- **视觉**：极简纸感黑白，米白纸面、墨色文字、发丝线，无彩色、无渐变、无投影。
- **同步**：本地 RDB 为唯一事实源；WebDAV 为主通道，分布式 KV 为同账号局域网增强通道；LWW + 冲突记录。
- **收笺入口**：分享扩展、HTML 导入、粘贴控件、碰一碰/隔空传送、内置浏览器。

## 明确边界

- 鸿蒙沙箱**无法读取其他浏览器书签库**；「浏览器书签同步」通过 HTML 导入 + 分享收笺 + 粘贴 + 内置浏览器实现。
- V1.0 不包含账号体系、社交、云托管、浏览器扩展、Android/iOS。
- 碰一碰、App Linking、分布式同步需要第二台设备与真实域名；应用接续已完成双机验证。
