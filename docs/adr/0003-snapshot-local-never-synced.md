# ADR-0003: 正文快照仅存本机，不参与同步

- 状态：Accepted
- 日期：2026-10-26（补记：原决策于 2026-10-21 基线，2026-10-22 结构化快照沿用）

## Context（背景）

「一笺三态」要求保存离线可读的正文快照，但快照若参与同步：①体积比元数据大一至两个数量级，
WebDAV 单条一文件的增量模型会被拖垮；②转载全文到用户网盘有版权与隐私放大效应；③多端对同一快照
的合并语义复杂（内容签名、抓取时间戳）。快照本质是「可再生的缓存」——只要有原始 URL，任何设备都能
重新抓取。

## Decision（决策）

正文快照存本机 `filesDir/snapshots/<id>.txt`（`FLOWPAGE-ARTICLE-2` 结构化格式，含链接区间），
**不上传同步**；同步只传链接、元数据、标签和状态。其他设备打开详情时按需重新抓取；旧格式
（`FLOWPAGE-ARTICLE-1`/纯文本）仍可读但无链接，需「重新抓取」升级。根书签阅读位置存本机
`flowpage_reader`，同样不参与同步。

## Consequences（后果）

- 同步负载小、速度快，WebDAV 增量模型成立。
- 新设备/清数据后首次打开快照需要网络且可能因原页变化或失效而失败（元数据仍可读）。
- 快照格式演进（v1→v2）不涉及同步兼容，只需本机读取兼容。
- 「原文 404 也能读」的保障只在抓取过快照的设备上成立，不跨端。
