# ADR-0001: 本地优先，RDB 为唯一事实源

- 状态：Accepted
- 日期：2026-10-26（补记：原决策于 2026-10-20 基线）

## Context（背景）

收藏类工具的常见形态是「云账号 + 服务端存储」：跨端容易，但用户数据不在自己手里，服务停摆即数据失联
（Pocket 关停是直接前车之鉴）。竞品中的隐私向用户（见 PRD Persona C）明确拒绝把书签交给 SaaS。
候选方案：云托管服务、纯单机无同步、本地优先 + 用户自有云。云托管需要后端运维与账号体系；
纯单机无法满足跨端接续的核心场景（J3）。

## Decision（决策）

本地优先：本地 RDB `flowpage.db` 是唯一事实源，所有数据先写本地、再由同步引擎异步上传；
任何同步失败不影响本地功能。不建账号体系，跨端能力交给用户自有的同步通道（见 ADR-0002）。

## Consequences（后果）

- 离线全功能可用；未开启同步时无任何数据出端。
- 同步层必须自行解决多端合并与冲突（LWW + 冲突表 + 墓碑），复杂度从服务端转移到端侧。
- 无法提供「换机即同步」的零配置体验，需要用户配置 WebDAV 或同账号组网。
- 数据导出（JSON + Netscape HTML）成为硬承诺，不制造锁定。
