# ADR-0008: 极简纸感黑白视觉方向

- 状态：Accepted
- 日期：2026-10-26（补记：原决策于 2026-10-20 PRD §13 已确认事项）

## Context（背景）

收藏/阅读类产品的视觉主流是彩色卡片流 + 封面缩略图。流笺的产品原则是「克制的美」：一屏一件事，
没有运营位与红点焦虑；差异化定位是「纸面收藏册」而非信息流应用。候选：跟随系统默认样式、彩色
内容卡片流、极简纸感黑白。

## Decision（决策）

极简纸感黑白：米白纸面、墨色文字、发丝线分隔；无彩色、无渐变、无投影。正文链接用下划线 + 墨色
呈现，不新增彩色 token。唯一例外是应用图标（朱红线穿纸的意象）。深浅两套颜色一律以
`$r('app.color.*')` 引用，`resources/base` 与 `resources/dark` 的 `color.json` 成对维护。

## Consequences（后果）

- 品牌辨识度高，与「纸笺」隐喻一致；渲染成本低。
- 没有彩色 token 意味着状态提示（错误、成功）只能靠文案、图标与明暗表达，设计约束记录在
  `docs/design/01-ui-spec.md`。
- token 纪律要求高：新增颜色必须成对维护深浅两套，否则深色模式会出现残留（AGENTS.md 已列红线）。
