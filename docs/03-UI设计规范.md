# 流笺 FlowPage · UI 设计规范

- 文档版本：v1.0（待确认）
- 视觉方向：极简纸感黑白
- 设计关键词：纸、墨、留白、克制、可读
- 适配：phone / tablet / 2in1 一多并重

---

## 1. 设计理念

**「纸是容器，墨是内容，留白是呼吸。」**

流笺不制造视觉噪音。界面像一册装帧克制的笺谱：米白纸面、墨色文字、发丝分隔线，唯一允许的装饰是数字与日期。所有颜色服务于可读性，所有动效服务于空间关系。

三条准则：

1. **内容优先**：标题、域名、摘要构成信息的全部；图标只做功能提示，不做装饰。
2. **一屏一事**：首页只负责「找与收」，详情只负责「读与整理」。
3. **黑白有层次**：不用彩色制造重点，用字重、字号、留白和发丝线建立秩序。

**明确不做**：渐变、玻璃拟态、彩色标签、投影卡片、大圆角、运营横幅、红点。

## 2. 设计 Token

### 2.1 色彩

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `paper` | `#F7F6F2` | `#0E0E0D` | 页面底色 |
| `surface` | `#FFFFFF` | `#171716` | 卡片、输入框、浮层 |
| `surface_alt` | `#EFEDE7` | `#1F1F1D` | 分组底、选中态 |
| `ink` | `#121211` | `#F2F0EA` | 主文字、主按钮 |
| `ink_secondary` | `#6E6C66` | `#A8A59E` | 次要文字、域名 |
| `ink_tertiary` | `#A3A09A` | `#6F6D67` | 时间、占位符 |
| `line` | `#E4E1D8` | `#2A2A27` | 发丝分隔线 |
| `line_strong` | `#CFCBC0` | `#3A3A36` | 输入框边框、强调分隔 |
| `inverse_ink` | `#F7F6F2` | `#0E0E0D` | 反色按钮文字 |
| `danger` | `#A33A2E` | `#D97364` | 删除、错误（仅此一处彩色） |
| `overlay` | `rgba(18,18,17,0.32)` | `rgba(0,0,0,0.56)` | 模态遮罩 |

规则：

- 彩色只用于破坏性操作与错误；成功状态用墨色 + 文案表达。
- 不使用色块标签；标签用 1vp 描边 + 透明底。
- 深色模式不是反色，而是「夜纸」：降低对比，避免纯黑纯白。

### 2.2 字体

字体族：`HarmonyOS Sans`（系统默认），数字使用等宽数字特性（`fontFeature: "tnum"` 若可用）。

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 34 / 42 fp | 600 | 页面主标题「流笺」 |
| Title | 24 / 32 fp | 500 | 详情标题、空状态标题 |
| Headline | 17 / 25 fp | 500 | 列表标题、分组标题 |
| Body | 15 / 24 fp | 400 | 摘要、正文 |
| Body Reading | 17 / 30 fp | 400 | 阅读模式正文 |
| Caption | 12 / 18 fp | 400 | 域名、时间、辅助说明 |
| Label | 12 / 16 fp | 500 | 按钮、标签、筛选 |

规则：

- 标题最多 2 行，超出省略；详情标题最多 4 行。
- 正文行宽 32–38 个汉字；2in1 阅读区最大 680vp。
- 不使用斜体；引用用左侧 2vp 竖线 + 二级文字色。
- 全大写仅用于英文短标签，中文不做字间距拉伸。

### 2.3 间距

基础网格 4vp，常用阶梯：

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72`

| 场景 | phone | tablet | 2in1 |
|---|---|---|---|
| 页面左右边距 | 20 | 32 | 40 |
| 列表项上下 | 16 | 18 | 16 |
| 分组间距 | 24 | 28 | 32 |
| 卡片内边距 | 16 | 20 | 20 |
| 图标与文字 | 8 | 8 | 8 |

### 2.4 圆角、描边、投影

| Token | 值 | 用途 |
|---|---|---|
| `radius_xs` | 2vp | 标签、选中指示 |
| `radius_sm` | 6vp | 输入框、按钮 |
| `radius_md` | 10vp | 卡片、浮层 |
| `radius_pill` | 999vp | 筛选 chip |
| `stroke` | 1vp | 所有分隔线与边框 |
| `shadow_modal` | `0 8 32 rgba(0,0,0,0.10)` | 仅半模态与菜单 |

**默认无投影。** 层级通过底色差异与发丝线表达。

### 2.5 动效

| Token | 值 | 用途 |
|---|---|---|
| `motion_fast` | 120 ms | 按压、hover、选中 |
| `motion_base` | 220 ms | 展开、切换、淡入 |
| `motion_slow` | 320 ms | 半模态、页面转场 |
| `spring` | stiffness 220 / damping 26 | 列表插入、卡片展开 |

- 页面 push：新页从右侧 16vp 滑入 + 透明度 0→1；pop 反向。
- 半模态：底部上滑 + 遮罩淡入；关闭时下滑，允许手势拖拽。
- 列表项进入：首屏前 8 条 20ms 递增淡入，滚动加载不逐条动画。
- 删除：高度收起 + 淡出 180ms，随后显示撤销 Snackbar。
- 尊重系统「减弱动态效果」：关闭位移与弹簧，仅保留淡入淡出。

## 3. 布局与断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| Compact | < 600vp | 单栏；底部安全区；详情 push |
| Medium | 600–840vp | 双栏：列表 360vp + 详情自适应；左侧窄导航 72vp |
| Expanded | > 840vp | 三栏：导航 240vp + 列表 380vp + 详情自适应 |

### 3.1 手机（Compact）

```
┌──────────────────────────────┐
│                  同步·  ⚙    │ 44
│                              │
│ 流笺                          │ 42
│ 128 条 · 今天收下 3 条         │ 18
│ ┌──────────────────────────┐ │
│ │ ⌕ 搜索标题、域名或摘录     │ │ 48
│ └──────────────────────────┘ │
│ [全部] [未读] [星标] [归档]    │ 36
│ ─────────────────────────────│
│ 标题两行……                    │
│ example.com · 3 天前          │
│ 摘要一行……                    │
│ ─────────────────────────────│
│ ……                            │
└──────────────────────────────┘
```

- 顶部不做传统导航栏，使用大标题 + 极简工具入口。
- 「收笺」主入口：右上角 `+` 文字按钮（20vp 图标）；分享与粘贴作为并列入口。
- 底部不设 TabBar：标签、同步、设置收进左上角「册」菜单，减少层级噪音。
- 列表使用分隔线而非卡片；首条与搜索框间距 20vp。

### 3.2 平板（Medium）

- 左侧 72vp 图标导航（流笺 / 标签 / 同步 / 设置），仅图标 + 选中竖线。
- 中间列表 360vp，右侧详情。
- 未选中时右侧显示「选一笺开始阅读」的留白空态。

### 3.3 2in1（Expanded）

- 左侧 240vp：品牌字标、导航、标签列表、同步状态。
- 中间 380vp：搜索 + 列表。
- 右侧：详情，阅读区居中最大 680vp。
- 支持 hover、右键菜单、键盘：
  - `Ctrl/⌘ + N` 收笺
  - `Ctrl/⌘ + F` 搜索
  - `Ctrl/⌘ + R` 同步
  - `↑ / ↓` 切换列表项，`Enter` 打开
  - `Esc` 关闭浮层
- 窗口宽度变化时使用同一套组件，不维护第二套 UI。

## 4. 组件规范

### 4.1 BookmarkRow（列表项）

| 属性 | 规格 |
|---|---|
| 高度 | 自适应，最小 88vp |
| 布局 | 纵向：标题（2 行）→ 摘要（1 行）→ 元信息行 |
| 标题 | Headline，`ink`，最多 2 行 |
| 摘要 | Body，`ink_secondary`，最多 1 行 |
| 元信息 | Caption：域名 · 相对时间 · 标签（最多 2 个） |
| 未读指示 | 标题左侧 2×16vp `ink` 竖条；已读无 |
| 分隔线 | 底部 1vp `line`，左右与文字对齐 |
| 按压 | 背景 `surface_alt`，120ms |
| 长按 / 右键 | 菜单：打开、复制链接、加星、归档、删除 |

不使用封面大图；封面仅在详情页顶部以 16:9 弱化展示（可选）。

### 4.2 FilterChip

- 高度 32vp，左右 12vp，pill 圆角，1vp `line_strong` 描边。
- 选中：`ink` 底 + `inverse_ink` 文字；未选中：透明底 + `ink_secondary`。
- 不显示数量角标，避免噪音；数量放页面副标题。

### 4.3 SearchField

- 高度 48vp，`surface` 底，1vp `line` 描边，圆角 6vp。
- 左侧 20vp 搜索图标 `ink_tertiary`；占位符「搜索标题、域名或摘录」。
- 聚焦：边框变 `ink`，无外发光。
- 右侧粘贴入口使用 `PasteButton`，样式为纯文字「粘贴」，不使用彩色。

### 4.4 TagPill

- 高度 22vp，左右 8vp，1vp `line_strong` 描边，透明底。
- 文字 Label，`ink_secondary`。
- 可点击进入标签筛选；不支持彩色。

### 4.5 Button

| 类型 | 规格 |
|---|---|
| Primary | `ink` 底，`inverse_ink` 文字，高 44vp，圆角 6vp，左右 20vp |
| Secondary | 透明底，1vp `line_strong`，`ink` 文字 |
| Text | 纯文字 + 下划线（仅链接场景） |
| Danger | `danger` 文字，仅用于二次确认弹窗 |

按压态：透明度 0.72；禁用态：`ink_tertiary` + 无按压反馈。

### 4.6 InboxSheet（收笺半模态）

```
┌──────────────────────────────┐
│           ────               │ 拖拽条
│ 收一笺                    ✕  │
│ ┌──────────────────────────┐ │
│ │ example.com              │ │
│ │ 文章标题（可编辑）         │ │
│ │ https://example.com/...  │ │
│ └──────────────────────────┘ │
│ 标签  [技术] [稍后读] [+ ]    │
│ 备注  ┌──────────────────┐   │
│       │ 可选               │   │
│       └──────────────────┘   │
│ ┌──────────────────────────┐ │
│ │          收 下            │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

- 高度 60–72%，最大 640vp；键盘弹出时内容可滚动。
- 链接卡使用 `surface_alt`，无阴影；标题可直接编辑。
- 标签建议最多 5 个，来自最近使用与导入文件夹。
- 「收下」为唯一主按钮；保存后 180ms 内关闭并轻提示。

### 4.7 详情页

```
┌──────────────────────────────┐
│ ←                         ⋯  │
│                              │
│ 一篇讲清楚分布式事务的文章    │ 28/36
│ example.com · 2026-10-12     │
│ [技术] [分布式]               │
│ ─────────────────────────────│
│ 原文  快照  摘录              │ 36 分段
│                              │
│ 正文……                        │
│                              │
│ ─────────────────────────────│
│ 收于 10 月 12 日 · 已读 3 次  │
└──────────────────────────────┘
```

- 顶部工具：返回、更多（复制、归档、删除、重新抓取）。
- 标题区与正文之间 24vp；正文最大宽度 680vp。
- 「原文 / 快照 / 摘录」使用下划线指示器，不使用胶囊。
- 快照缺失时展示「尚未保存正文 · 重试」，不显示空白。

### 4.8 导入流程

三步：选择文件 → 预览与选项 → 完成报告。

- 预览卡：总条数、文件夹数、重复数、预计耗时。
- 选项：保留文件夹为标签（默认开）、跳过重复（默认开）。
- 进度：细线进度条 + 「已处理 320 / 1200」，不阻塞其他操作。
- 报告：成功 / 跳过 / 失败三段，失败可复制。

### 4.9 同步中心

- 顶部状态行：`上次同步 2 分钟前 · 已同步`，状态点用墨色圆点（异常用 `danger`）。
- WebDAV 表单：地址、账号、应用密码、远端目录；「测试连接」为 Secondary 按钮。
- 冲突记录：列表项显示两条标题与时间，操作「保留本地 / 采用远端」。
- 分布式通道独立分组，显示「同账号可信设备」与开关。

### 4.10 服务卡片

| 尺寸 | 内容 |
|---|---|
| 2×2 | 「今日笺」+ 标题 2 行 + 域名；点击直达详情 |
| 2×4 | 标题 + 最近 3 条（标题 + 域名） |

- 背景 `paper`，1vp `line` 边框，圆角 12vp（卡片系统限制内）。
- 无图片、无彩色；仅文字与一条 24vp 竖线。
- 空状态：「去收第一笺」。

### 4.11 分享扩展面板

- 宽度跟随系统半模态，内容压缩为：链接预览 + 标签 + 「收下」。
- 不显示完整设置与导航；处理完成即关闭。
- 失败提示使用系统 Toast，不弹自定义对话框。

---

## 5. 图标与插画

- 统一使用 HarmonyOS Symbol（`sys.symbol.*`），线性、1.5vp 描边、20/24vp。
- 功能图标：搜索、加号、星标、归档、更多、同步、设置、标签、外部链接、剪贴板。
- 不使用彩色图标；选中态仅改变颜色与字重。
- 空状态插画：单色细线，主题为「纸、抽屉、书签」，尺寸 120–160vp，不作装饰性大图。

## 6. 空状态、加载与错误

| 场景 | 文案 | 视觉 |
|---|---|---|
| 首页无收藏 | 「还没有笺。收下第一条链接，纸就有了内容。」+ 收笺 / 导入 | 细线书签插画 |
| 搜索无结果 | 「没有找到。换个词，或去标签里翻翻。」 | 无插画 |
| 详情无快照 | 「这条还没存下正文。」+ 重试 | 虚线框 |
| 同步未配置 | 「数据只在这台设备上。」+ 配置同步 | 墨点 |
| 同步失败 | 「这次没同步上。链接还在，稍后再试。」+ 查看原因 | `danger` 圆点 |
| 导入失败 | 「文件没读懂。请确认是浏览器导出的 HTML。」 | 无 |

加载：

- 首屏使用骨架屏（2–3 条灰线），不使用转圈。
- 局部加载使用 16vp 细线旋转，仅出现在按钮内。

## 7. 文案语气

- 短句、动词开头、不用感叹号。
- 专业但不冷漠；可以有一点文气，不堆砌古风。
- 示例：
  - 主按钮：「收下」「导入」「开始同步」
  - 空状态：「纸还空着。」
  - 删除确认：「删除这一笺？30 天内可恢复。」
  - 同步失败：「没同步上。链接还在，稍后再试。」

---

## 8. 无障碍

- 正文对比度 ≥ 4.5:1；次要文字 ≥ 4.5:1（`#6E6C66` on `#F7F6F2` 约 5.1:1）。
- 可点击区域 ≥ 44×44vp；图标按钮补足热区。
- 支持系统字体缩放：布局使用自适应高度，标题最多行数随字号调整。
- 所有图标按钮提供 `accessibilityText`；列表项朗读「标题，域名，时间，未读」。
- 键盘焦点环：1.5vp `ink` 外框，偏移 2vp。
- 不只靠颜色表达状态：未读同时有竖条，错误同时有文案。

---

## 9. 动效与手势

| 手势 | 行为 |
|---|---|
| 下拉 | 触发同步（未配置时提示） |
| 左滑列表项 | 加星（短滑）/ 归档（长滑） |
| 右滑列表项 | 删除，显示撤销 |
| 长按列表项 | 上下文菜单 |
| 双指捏合 | 列表密度切换（紧凑 / 舒适），P2 |
| 半模态下拉 | 关闭 |

所有手势提供替代操作（菜单/按钮），不做隐藏唯一入口。

## 10. 视觉走查清单

- [ ] 页面是否只有一个视觉重心？
- [ ] 是否出现彩色（除删除/错误）？
- [ ] 是否出现不必要的投影、渐变、玻璃？
- [ ] 标题、摘要、元信息三级层次是否清晰？
- [ ] 发丝线是否对齐文字基线？
- [ ] 深色模式下是否仍可读，是否避免纯黑纯白？
- [ ] 手机 / 平板 / 2in1 三断点是否无横向滚动、无挤压？
- [ ] 空状态、加载、错误是否都有文案？
- [ ] 所有图标按钮是否有无障碍标签？
- [ ] 键盘操作是否可完成主流程？
- [ ] 动效是否可被系统「减弱动态效果」关闭？
