## 1. 一句话定位

**流笺是一款本地优先的链接收笺工具：把散落在浏览器、微信和各设备里的链接，三秒收进一册可离线、可搜索、可同步的「笺」里。**

不是书签管理器的替代品，而是书签的**上游入口**与**下游存档**。

---

## 2. 背景与机会

### 2.1 用户正在丢失自己的收藏

- 浏览器书签被锁在单一生态里：Chrome 依赖 Google 账号，国内长期不可用；Edge、Safari、华为浏览器各自为政。
- 鸿蒙新设备迁移时，没有顺手的书签搬运工具；用户只能导出 HTML 再手动整理。
- 微信、公众号、小红书等 App 内的内容没有统一收藏出口，「转发给自己」成为事实上的收藏夹，且不可检索。
- 收藏行为极其廉价，导致「收藏即吃灰」：只存 URL，标题会变、页面会 404、内容会删。
- 国外工具（Raindrop、Pinboard）访问慢、订阅贵；开源自建（Floccus、Linkwarden）门槛高、界面粗糙。

### 2.2 竞品观察

> 信息来源：各产品公开页面、应用商店评论、中文社区讨论的归纳；价格为撰写时点的大致区间，以官网为准。

| 产品 | 形态 | 做得好的 | 用户主要不满 | 对流的启示 |
|---|---|---|---|---|
| Raindrop.io | 全平台收藏 | 分类、预览、全文检索完整 | 国内访问不稳定；Pro 订阅；客户端偏重；无鸿蒙端 | 能力标杆，但「重」且「远」 |
| Pocket | 稍后读 | 极简、阅读体验好 | 2025 年 7 月已关停，用户被迫迁移 | 迁移窗口仍在；「读」比「存」更有价值 |
| Pinboard | 老牌书签 | 快、纯链接、稳定 | 界面陈旧、收费、无中文、无移动体验 | 极简可行，但不能只有链接 |
| Cubox | 国内收藏 | 本土化、AI 摘要、微信入口 | 订阅制、导出受限、隐私顾虑、无鸿蒙端 | 本土化方向对，信任与开放不足 |
| 浏览器自带同步 | 系统能力 | 零成本、无感 | 生态锁定；跨浏览器不通；迁移困难 | 不与之竞争，做它们的「汇总层」 |
| xBrowserSync / Floccus / Linkwarden | 开源自建 | 隐私、自由、可自托管 | 配置复杂、UI 简陋、移动端弱 | 自托管能力要保留，但体验必须产品化 |

### 2.3 机会窗口

1. **Pocket 关停后的迁移需求**：大量「稍后读」用户正在寻找可信、可导出的替代品。
2. **鸿蒙生态缺少「本地优先」的收藏工具**：现有方案要么是浏览器自带、要么是云端订阅，端侧隐私与自托管是空白。
3. **国内多浏览器长期并存**：用户需要的不是某个浏览器的同步，而是一个跨浏览器的「收口」。
4. **系统能力成熟**：分享扩展、服务卡片、碰一碰、应用接续、分布式数据，足以支撑「无感收笺」的差异化体验。

### 2.4 必须对齐的产品边界

鸿蒙应用运行在沙箱内，**无法读取其他浏览器的书签数据库**，也无法向第三方浏览器注入扩展。因此「浏览器书签同步」在本产品中的真实含义是：

1. 解析浏览器导出的 `bookmarks.html`（Chrome / Edge / Safari / Firefox / 华为浏览器）；
2. 通过系统分享面板从任意 App 收链接；
3. 通过粘贴控件读取剪贴板链接；
4. 内置浏览器中边看边收；
5. 通过 WebDAV / 分布式数据在流笺自己的多端之间同步。

**不做**「伪造的浏览器同步协议」，也不承诺读取系统浏览器内部数据。

## 3. 目标用户

### Persona A · 研究生 / 初级开发者「小林」24 岁

- 设备：Windows 笔记本 + 鸿蒙手机 + 平板
- 浏览器：Chrome（工作）+ Edge（学校）+ 手机浏览器
- 行为：看到教程、论文、GitHub 就收藏，之后再也没打开
- 痛点：收藏散落三处；换设备找不到；链接失效后不知道原文是什么
- 诉求：一个地方收、能搜到、最好存一份正文

### Persona B · 产品经理「老王」35 岁

- 设备：鸿蒙手机 + MatePad + 鸿蒙 PC
- 行为：大量阅读公众号、行业报告、竞品页面，经常在通勤时收藏、到工位再读
- 痛点：微信里收藏的内容无法跨端；复制链接再切 App 太繁琐；PC 上找不到手机收藏的那篇
- 诉求：分享即收、跨端接续、桌面卡片提醒回看

### Persona C · 隐私敏感者「阿澈」29 岁

- 设备：鸿蒙手机 + NAS + 自建服务
- 行为：拒绝把书签交给国外 SaaS；愿意为可控付费
- 痛点：Raindrop 慢且不可控；Floccus 配置复杂；没有鸿蒙客户端
- 诉求：数据默认在本地；可接自己的 WebDAV；凭据加密；可完整导出

## 5. 产品原则

1. **收得快**：任何入口的收笺路径不超过 3 步；分享面板一步直达。
2. **存得住**：链接不是资产，内容才是；默认保存可读文本快照。
3. **找得回**：搜索优先于层级；标签是辅助，不是负担。
4. **默认私密**：本地优先，不上传、不埋点；云同步是用户主动开启的能力。
5. **克制的美**：一屏只做一件事；没有运营位、没有推荐流、没有红点焦虑。

## 6. 差异化设计

### D1 · 一笺三态：链接 + 快照 + 摘录

每条收藏同时拥有：原始链接、离线可读的正文快照、用户自己的摘录。页面 404 后仍可阅读与检索。这是对「收藏即吃灰」的正面回应。

### D2 · 鸿蒙原生「三秒收笺」

- **分享扩展**：任意 App 分享面板常驻「流笺」，不跳主界面即可完成收笺。
- **粘贴控件**：首页常驻粘贴入口，用户点击即读剪贴板，不弹权限骚扰。
- **碰一碰 / 隔空传送**：链接从手机一碰即达 PC，直达详情页。

### D3 · 反吃灰：时光轴与每日一笺

首页以时间流呈现，而非文件夹树；服务卡片每天推一条旧收藏；详情页提供「再读一次」。让收藏重新流动起来。

### D4 · 本地优先 + 自己的云

默认纯本地；同步支持两条通道：
- **WebDAV**：坚果云、群晖、Alist 等，跨网络、跨品牌；
- **分布式数据**：同账号可信设备、同一局域网内零配置同步。

凭据使用 HUKS 加密；支持完整导出，不制造数据锁定。

## 9. 核心流程

### 9.1 分享收笺（主路径）

1. 用户在浏览器/微信点击分享。
2. 分享面板出现「流笺」。
3. 打开轻量收笺面板：链接、自动标题、站点、标签建议。
4. 点击「收下」→ 写入本地 → 后台补全摘要与快照 → 面板关闭。
5. 若抓取失败，不阻塞保存，详情页显示「待补全」。

**成功标准**：从点击分享到保存成功 ≤ 3 秒（不含网络补全）。

### 9.2 HTML 导入

1. 设置 → 导入 → 选择 `bookmarks.html`。
2. 解析预览：共 N 条、M 个文件夹、K 条重复。
3. 选择「保留文件夹为标签」。
4. 事务批量写入，展示进度。
5. 结果报告：成功 / 跳过重复 / 失败，可导出失败清单。

### 9.3 跨端同步（WebDAV）

1. 同步中心 → 添加 WebDAV：地址、账号、应用密码。
2. 连接测试 → 选择远端目录（默认 `/FlowPage/`）。
3. 首次同步：拉取远端 → 与本地按 `id` 合并 → 上传差异。
4. 后续同步：比较 ETag 与本地版本，增量上传/下载。
5. 冲突：同一 `id` 双方均修改 → 按 `updatedAt` 保留较新版本，旧版本进入「冲突记录」，可手动恢复。

### 9.4 找回

1. 首页搜索框输入关键词（标题/域名/摘要/摘录/URL）。
2. 结果即时过滤，命中词高亮。
3. 打开详情 → 原文按钮 / 快照阅读。
4. 可标记已读、加星、加标签。

## 10. 关键业务规则

### 10.1 去重

- 规范化 URL 后生成 `url_key`：小写 scheme/host、移除默认端口、移除 `utm_*`/`spm`/`from` 等追踪参数、移除 fragment、query 排序。
- 同一 `url_key` 已存在时：不新增，更新标题/摘要，并提示「已收过」。
- 导入时重复项计入「跳过」，不覆盖用户备注。

### 10.2 快照

- 默认抓取结构化正文块（标题 / 段落 / 引用 / 列表 / 代码，上限 204800 字符），保留层级与段落结构。
- 图片不落盘（V1.0），避免存储膨胀；封面仅存 URL。
- 快照失败不阻塞收笺，状态标记为 `pending`，可在详情页重试。
- 用户可关闭「自动保存快照」以省流量。

### 10.3 标签

- 标签名 1–24 字符，去首尾空格，大小写不敏感去重。
- 导入的文件夹路径转为层级标签，例如 `技术/前端`。
- 删除标签不删除书签，仅解除关联。

### 10.4 回收站

- 删除为软删除，保留 30 天；期间可恢复。
- 同步删除使用墓碑记录，30 天后物理清理。

### 10.5 冲突

- 以 `updatedAt`（毫秒）为准的 Last-Write-Wins。
- 双方字段级差异不自动合并（V1.1 简化策略），败方完整快照进入冲突表。
- 冲突记录保留 30 天，可一键恢复为当前版本。

### 10.6 阅读状态

- `unread`（默认）→ `reading`（打开详情或原文）→ `read`（手动标记、阅读 30 秒，或阅读进度 ≥90%）。
- 首页默认按 `createdAt` 倒序，可切换「最近阅读」。

## 12. 风险与假设

| 风险 | 影响 | 应对 |
|---|---|---|
| 网页反爬/需登录，元数据抓取失败 | 标题与摘要缺失 | 降级为域名 + URL；允许手动编辑；不阻塞保存 |
| 国内站点 GBK/GB2312 编码 | 摘要乱码 | 显式 charset 检测与解码兜底 |
| WebDAV 服务商实现差异 | 同步失败 | 仅用标准方法；连接测试分级提示；支持坚果云/群晖验证 |
| 碰一碰/App Linking 需域名校验 | 无法真机演示 | 保留自定义 scheme 兜底；域名校验作为发布项 |
| 分布式同步需同账号与组网 | 演示受限 | 以 WebDAV 为主通道，分布式为增强 |
| 单设备环境 | 跨端无法完整验收 | 2in1 真机 + 预览器；必要时请用户提供第二台设备 |
| 全设备一多工作量大 | 首版质量风险 | 断点复用组件；先手机布局，再平板/PC 分栏 |
