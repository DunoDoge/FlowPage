# 流笺 FlowPage · 当前版本走查清单

- 版本：批次 A + B + C 隐私/阅读增强
- 设备：HUAWEI Pura 70（手机）、HUAWEI MateBook Pro（2in1）
- 数据：两端各 6 条演示数据；可在「设置 → 清空所有数据」清除
- 同步：验证用 WebDAV 服务已停止，两端配置已断开

## 1. 手机（Pura 70）

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开流笺 | 纸感首页，标题「流笺」，6 条演示数据 |
| 2 | 点「+ 收笺」，输入任意 URL，收下 | 立即出现在列表；标题/摘要在网络可用时自动补全 |
| 3 | 在系统浏览器分享一个链接 → 选「流笺」 | 分享面板内自动带出 URL 与标题，收下后返回 |
| 4 | 复制一个 URL → 点首页「粘贴」 | 无权限弹窗，直接打开收笺面板并预填 URL |
| 5 | 设置 → 导入浏览器书签 → 选 `bookmarks.html` | 显示成功/重复/失败统计，文件夹变为标签 |
| 6 | 首页搜索关键词，或点「标签」选一个标签 | 结果即时过滤，标签与关键词可叠加 |
| 7 | 打开一条笺 → 编辑标题/标签/备注 → 保存 | 返回列表后标题/标签更新 |
| 8 | 详情 → 查链接 | 显示「链接可用 / 可能失效 / 暂时无法判断」 |
| 9 | 详情 → 正文 → A− / A+ | 字号与行高变化，退出再进入仍保留 |
| 10 | 详情 → 加星 / 归档 / 删除 | 列表星标、归档筛选、回收站状态正确 |
| 11 | 设置 → 深色 / 浅色 / 跟随系统 | 立即切换，重启后保持 |
| 12 | 桌面长按 → 服务卡片 → 流笺 | 2×2「今日笺」/ 2×4「最近」；当前桌面自动化受限，此项可能无法自动完成 |
| 13 | 回收站 → 打开一条笺 → 恢复 / 彻底删除 | 恢复后回到列表；彻底删除后记录与正文快照消失 |
| 14 | 回收站为空 | 只显示「回收站是空的」提示，不显示「收第一笺 / 导入书签」 |
| 15 | 打开一条笺 → 返回首页 | 该行不保留按住/选中底色，可继续打开其他书签 |

## 3. 同步（需要你提供 WebDAV）

当前两端已断开同步。用坚果云验证时：

1. 坚果云 → 设置 → 安全 → 添加应用密码。
2. 流笺 → 同步 → 地址 `https://dav.jianguoyun.com/dav/`，账号为邮箱，密码为应用密码。
3. 点「连接并同步」，首次应上传本地 6 条。
4. 在另一台设备配置同一账号，点「连接并同步」，应下载 6 条。
5. 在手机改标题/加星 → 同步；PC 同步后应看到变化。

也可让我重新启动本地测试 WebDAV 服务，用 `http://<电脑IP>:8080/`、`demo / demo` 复现，不需要真实账号。
