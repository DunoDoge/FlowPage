# 流笺 FlowPage

把散落在浏览器、聊天和剪贴板里的链接收进一册可离线、可搜索、可同步的「笺」。

FlowPage 是一款本地优先的 HarmonyOS 链接收笺应用：数据先落在本机 RDB，WebDAV 只负责在设备之间增量同步；
没有账号体系，也不依赖云端即可使用。支持手机、平板与 2in1。

## 功能

- **收笺**：手动输入、粘贴板识别、系统分享扩展、浏览器 HTML 书签导入。
- **整理**：标签、未读/星标/归档/回收站、全文搜索（标题、域名、描述、摘录、备注、标签）。
- **阅读**：抓取标题/摘要/站点/图标，保存含链接区间的结构化正文快照；正文、摘录、备注三态阅读与编辑，
  字号/行距/段距可调；专注阅读支持搜索/目录/进度/摘录，正文链接可在阅读模式中逐层打开。
- **浏览**：单标签应用内浏览器，可编辑地址、前进/后退/刷新，并可在「网页 / 阅读」间切换；链接页默认临时阅读，
  可手动收笺。
- **同步**：标准 WebDAV（坚果云、群晖、Alist 等），按 ETag 增量、LWW 合并、墓碑删除，凭据经 HUKS 加密后落盘；
  正文快照不上传。
- **系统能力**：`flowpage://bookmark/{id}` 深链、应用接续、系统分享面板、2×2「今日笺」与 2×4「最近」服务卡片。
- **一多**：手机单栏、平板两栏、2in1 三栏；米白纸感黑白主题，支持跟随系统/浅色/深色。
