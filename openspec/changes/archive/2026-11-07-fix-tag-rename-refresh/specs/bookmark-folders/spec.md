# Spec Delta

## MODIFIED Requirements

### Requirement: 文件夹改名与移动
改名或移动文件夹 SHALL 仅变更该文件夹自身记录，不重写成员书签；移动 MUST 拒绝把文件夹放到它自己的子孙之下。移动可经行「…」菜单或拖拽发起。改名结果 SHALL 同步到当前已打开的文件夹展示面（详情页文件夹 chip、文件夹选择器），无需用户切换页面。

#### Scenario: 改名不扰动成员
- **WHEN** 含 500 条书签的文件夹被改名
- **THEN** 全部成员书签的归属与内容不变，仅文件夹记录发生一次变更

#### Scenario: 拖拽移动不重写成员
- **WHEN** 含 500 条书签的文件夹被拖到另一个文件夹下
- **THEN** 仅该文件夹记录变更，成员书签的归属与内容不变

#### Scenario: 移入自身子孙被拒绝
- **WHEN** 用户试图把「开发」移动到「开发/前端」之下
- **THEN** 系统拒绝该操作并提示不允许形成循环

#### Scenario: 改名后详情页文件夹名称同步
- **WHEN** 某书签详情页正处于打开状态，其所属文件夹在侧栏被改名为「新名」
- **THEN** 详情页的文件夹 chip 立即显示「新名」，无需返回主页或重新进入详情

#### Scenario: 改名后文件夹选择器显示新名称
- **WHEN** 文件夹选择器已加载过某文件夹，随后该文件夹被改名或由同步更新
- **THEN** 选择器中该行立即显示新名称与正确计数，不保留旧名称
