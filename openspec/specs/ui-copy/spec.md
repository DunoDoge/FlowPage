# ui-copy Specification

## Purpose

约束应用公开展示面上的文案与占位元素：不出现未实现功能的预告占位、不出现产品定位式短语，同时保住用户决策所需的数据行为告知，并保证版本号与包配置一致。

## Requirements

### Requirement: 不出现未实现功能的占位 UI

正式展示面 SHALL NOT 包含为未实现功能预埋的预告性区块或入口（如「将在下一阶段接入」式卡片）。功能未实现时不得在 UI 中宣传；实现后再随其变更提案进入展示面。

#### Scenario: 同步页无「分布式」占位卡

- **WHEN** 用户打开同步页并滚动到底部
- **THEN** 不存在标题为「分布式」、描述「下一阶段接入」的区块，页面以既有冲突记录等真实功能区块收尾

#### Scenario: 全应用无预告式占位

- **WHEN** 遍历应用全部页面（主页、标签、同步、设置、阅读层、分享页、桌面卡片）
- **THEN** 不存在指向尚未实现功能（分布式协同、App Linking 域名、多标签浏览器等）的可见文案或入口

### Requirement: 不展示产品定位式短语

导航结构与功能页 SHALL NOT 展示定位/抒情式 slogan（如「本地优先 / 数据在这台设备上」侧边栏 footer、「没有账号、没有推荐、没有埋点」式 tagline、「文件夹记得来处」式页面副题）。界面文案只保留：操作标签、状态与结果反馈、引导与数据行为告知。

#### Scenario: 宽屏侧边栏无 footer slogan

- **WHEN** 应用以 ≥1000vp 宽度运行并查看左侧导航栏
- **THEN** 导航栏底部导航项与文件夹面板之后不渲染任何 slogan 文案区块

#### Scenario: 设置「关于」无 tagline、标签页无副题

- **WHEN** 用户分别打开设置页「关于」区块与标签页
- **THEN** 「关于」处不展示产品定位句，标签页标题下不展示抒情副题；两处其余功能内容不受影响

### Requirement: 功能性告知文案保留

文案精简 SHALL NOT 移除用户决策所需的功能性告知：数据行为与隐私说明（同步上传范围、清空本机数据的云端语义、不读取其他浏览器的书签数据库声明）、空状态引导、输入占位提示、操作结果反馈与确认弹窗。

#### Scenario: 同步页数据行为说明仍在

- **WHEN** 用户打开同步页
- **THEN** 仍能看到关于同步上传范围的说明（只上传链接与标签，不上传正文快照）及未配置/已断开时的数据所在状态提示

#### Scenario: 清空数据的语义说明仍在

- **WHEN** 用户查看设置页「清空本机数据」行并触发其确认弹窗
- **THEN** 行内提示与弹窗正文仍完整说明「云端保留、下次同步会恢复」的语义

### Requirement: 设置页版本号与包配置一致

设置页展示的版本号 MUST 在运行时取自包配置的 `versionName`，不得在代码中硬编码版本字符串。

#### Scenario: 版本升级后显示自动跟随

- **WHEN** 包配置中的 `versionName` 从 1.0.0 升级为后续版本并重新构建安装
- **THEN** 设置页显示的版本号随之变化，无需修改界面代码
